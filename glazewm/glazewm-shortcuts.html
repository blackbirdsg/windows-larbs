GlazeWM Shortcuts

Windows

Alt + jNext window in current workspace
Alt + h/lFocus left/right
Alt + Shift + h/j/k/lMove focused window
Alt + qClose focused window
Alt + fToggle fullscreen
Alt + Shift + SpaceToggle floating
Alt + Shift + tToggle tiling

Workspaces

Alt + 1..9Switch workspace
Alt + Shift + 1..9Move window to workspace and follow it
Alt + , / .Previous/next active workspace
